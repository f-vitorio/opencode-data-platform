# Copywriting

Base de conhecimento para comunicação comercial.

## Subáreas

- headlines
- propostas de valor
- benefícios
- mecanismos
- provas
- objeções
- CTA
- anúncios
- landing pages
- VSL
- conteúdo
- posicionamento

## Regra

Não inventar:
- resultados
- depoimentos
- números
- garantias
- autoridade
- cases

Qualquer afirmação factual deve ter origem identificável.
