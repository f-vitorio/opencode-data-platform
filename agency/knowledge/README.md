# AGENCY KNOWLEDGE BASE

Esta é a camada de conhecimento operacional da agência.

## Fluxo

SOURCE
→ VALIDATION
→ CLASSIFICATION
→ KNOWLEDGE
→ APPLICATION
→ EXPERIENCE
→ IMPROVEMENT

## Princípio

A base deve ficar melhor com o tempo.

Não buscamos simplesmente acumular documentos.

Buscamos acumular:

- conhecimento verificável;
- metodologias úteis;
- experiências documentadas;
- hipóteses testadas;
- aprendizados reutilizáveis.
