# Base de Conhecimento da Agência

Esta é a base central de conhecimento da operação.

## Hierarquia

1. Material específico fornecido pelo usuário
2. Experiência, dados e cases próprios da agência
3. Documentação oficial das plataformas
4. Fontes externas confiáveis
5. Conhecimento geral

## Regra principal

A base externa serve como ponto de partida.

Ela NÃO deve substituir:
- preços definidos pela agência;
- processos próprios;
- cases próprios;
- resultados comprovados;
- posicionamento comercial;
- regras internas.

Quando material próprio for incorporado, ele deverá ter prioridade sobre conhecimento externo quando houver conflito.

## Objetivo

Construir progressivamente um sistema operacional de conhecimento para:

- Google Ads
- Landing Pages
- CRO
- SEO
- UX/UI
- Copywriting
- Vendas e negociação
- Analytics e tracking
- Estratégia de agência
- Cases e experimentos
