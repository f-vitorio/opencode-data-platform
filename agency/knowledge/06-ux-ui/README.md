# UX/UI

Base para experiência e interface.

## Subáreas

- hierarquia visual
- acessibilidade
- navegação
- legibilidade
- responsividade
- formulários
- feedback
- consistência
- design systems
- mobile
- conversão

## Princípio

Design deve facilitar compreensão e ação.

Não priorizar estética em detrimento de clareza, acessibilidade ou conversão.
