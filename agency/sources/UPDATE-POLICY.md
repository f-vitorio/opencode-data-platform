# POLÍTICA DE ATUALIZAÇÃO DAS FONTES

## Quando atualizar

Atualizar fontes quando houver:

- mudança de política
- mudança de produto
- mudança de documentação
- nova versão de padrão
- mudança relevante de mercado
- descoberta de informação que contradiga material anterior.

## Prioridade

1. documentação oficial atual
2. fonte primária
3. pesquisa confiável
4. benchmark
5. conhecimento geral.

## Não sobrescrever silenciosamente

Quando uma informação importante mudar:

1. registrar a nova informação
2. registrar a fonte
3. registrar a data
4. identificar a informação anterior
5. avaliar se algum conhecimento interno precisa ser atualizado.

## Regra

Uma informação antiga não deve ser apagada simplesmente porque foi
substituída.

Quando histórico for relevante, preservar a evolução.
