## Requisitos mínimos

Para uma página ser elegível à indexação, o Google destaca
requisitos técnicos básicos:

1. Googlebot não deve estar bloqueado;
2. a página deve funcionar e retornar HTTP 200;
3. a página deve possuir conteúdo indexável.

## Observação importante

Cumprir os requisitos técnicos não garante que uma página
será indexada.
