# UX/UI — Fundamentos

## Objetivo

Criar interfaces que permitam ao usuário compreender, navegar e executar
ações com o menor atrito possível.

## UX

UX envolve:

- necessidades do usuário
- arquitetura da informação
- navegação
- interação
- clareza
- feedback
- acessibilidade
- contexto de uso.

## UI

UI envolve:

- hierarquia visual
- tipografia
- espaçamento
- contraste
- componentes
- layout
- consistência
- estados de interação.

## Regra

Design não deve ser avaliado apenas pela aparência.

A pergunta principal é:

"Isso ajuda o usuário a entender e realizar o que precisa?"
