# UX para Landing Pages

## Objetivo

Reduzir incerteza e facilitar a decisão.

## Estrutura de avaliação

1. proposta de valor
2. clareza
3. prova
4. benefícios
5. objeções
6. oferta
7. CTA
8. formulário
9. confiança
10. experiência mobile.

## Perguntas

- O visitante entende rapidamente o que está sendo oferecido?
- Para quem é?
- Qual problema ou necessidade é atendida?
- Por que confiar?
- O próximo passo está claro?
- Existem distrações?

## Regra

Não remover informação simplesmente para deixar a página "mais limpa".

Clareza e informação necessária devem ser preservadas.
