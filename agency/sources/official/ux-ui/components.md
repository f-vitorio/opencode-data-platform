# UX/UI — Componentes

## Componentes comuns

- botão
- link
- input
- select
- checkbox
- radio
- card
- modal
- menu
- navegação
- alerta
- tooltip.

## Para cada componente

Avaliar:

- estado padrão
- hover
- foco
- ativo
- desabilitado
- erro
- sucesso
- carregamento.

## Regra

Componentes reutilizáveis devem apresentar comportamento consistente
em todo o produto.
