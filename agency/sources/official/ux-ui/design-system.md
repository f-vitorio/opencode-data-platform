# UX/UI — Design System

## Objetivo

Criar consistência visual e comportamental.

## Elementos

- tokens
- cores
- tipografia
- espaçamento
- grid
- componentes
- estados
- padrões de interação.

## Benefícios

- consistência
- velocidade de produção
- manutenção
- escalabilidade
- qualidade.

## Regra

Não criar um design system apenas para adicionar documentação.

Ele deve resolver problemas reais de consistência e produção.
