# WCAG — Estrutura de Avaliação

## Princípios

WCAG organiza acessibilidade em quatro princípios:

1. Perceptível
2. Operável
3. Compreensível
4. Robusto

## Aplicação

Durante auditorias, avaliar cada princípio separadamente.

## Importante

Conformidade deve ser determinada com base na versão e critérios
aplicáveis da WCAG utilizada no projeto.

Não declarar conformidade sem avaliação adequada.

## Fonte

W3C Web Accessibility Initiative.
