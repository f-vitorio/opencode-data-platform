# Performance como UX

## Princípio

Desempenho técnico afeta a experiência percebida.

## Avaliar

- carregamento
- resposta a interação
- estabilidade visual
- imagens
- fontes
- scripts
- recursos de terceiros.

## Regra

Otimizar performance sem destruir funcionalidade ou qualidade da experiência.

Priorizar problemas de impacto real.
