# UX/UI — Hierarquia Visual

## Objetivo

Organizar elementos de forma que o usuário consiga identificar rapidamente
o que é mais importante.

## Hierarquia

Avaliar:

- tamanho
- posição
- contraste
- espaçamento
- agrupamento
- tipografia
- repetição
- alinhamento.

## Perguntas

- Qual é o primeiro elemento percebido?
- O objetivo da página fica claro?
- Existe uma ação principal?
- Elementos secundários competem com a ação principal?
- O conteúdo está visualmente organizado?

## Regra

Toda página deve possuir uma hierarquia perceptível.
