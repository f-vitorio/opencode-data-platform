# Acessibilidade Web

## Objetivo

Permitir que pessoas com diferentes capacidades possam acessar e utilizar
a interface.

## Áreas

### Percepção
- contraste
- textos alternativos
- estrutura semântica
- conteúdo não dependente exclusivamente de cor.

### Operação
- navegação por teclado
- foco visível
- controles acessíveis
- áreas de interação adequadas.

### Compreensão
- linguagem clara
- labels
- instruções
- mensagens de erro compreensíveis.

### Compatibilidade
- HTML semântico
- tecnologias assistivas
- comportamento previsível.

## Referência principal

WCAG — Web Content Accessibility Guidelines.

## Regra

Acessibilidade deve ser considerada desde a estrutura da interface,
não apenas como uma correção posterior.
