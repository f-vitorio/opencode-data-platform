# UX/UI — Mobile

## Prioridade

Avaliar a experiência em telas pequenas antes de assumir que desktop
é a referência principal.

## Verificar

- legibilidade
- tamanho dos elementos
- espaçamento
- navegação
- botões
- formulários
- velocidade percebida
- conteúdo acima da dobra
- orientação
- overflow horizontal.

## Regra

Não simplesmente reduzir o layout desktop.

A experiência deve ser adaptada ao contexto mobile.
