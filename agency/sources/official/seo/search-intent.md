# SEO — Intenção de Busca

## Tipos comuns

- informacional
- navegacional
- comercial
- transacional
- local

## Processo

Antes de criar ou otimizar uma página:

1. identificar a consulta
2. inferir a intenção
3. analisar o tipo de resultado apresentado
4. determinar qual necessidade o usuário está tentando resolver
5. construir uma resposta compatível

## Regra

Não criar uma página apenas porque uma palavra-chave possui volume.

A página precisa ter uma função clara dentro da jornada do usuário.
