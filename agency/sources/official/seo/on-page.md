# SEO — On-Page

## Elementos

Avaliar:

- title
- meta description
- H1
- headings
- conteúdo
- entidades e conceitos relacionados
- links internos
- URLs
- imagens
- alt text
- elementos estruturais

## Princípio

Otimização on-page deve melhorar:

- compreensão
- relevância
- navegação
- experiência.

## Regra

Não inserir palavras-chave artificialmente apenas para aumentar densidade.
