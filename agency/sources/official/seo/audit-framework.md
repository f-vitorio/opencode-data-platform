# SEO — Auditoria

## Ordem sugerida

### 1. Acesso
O site está acessível?

### 2. Rastreamento
Os mecanismos conseguem encontrar as páginas?

### 3. Indexação
As páginas importantes estão indexáveis?

### 4. Arquitetura
A estrutura é lógica?

### 5. Conteúdo
As páginas respondem às intenções relevantes?

### 6. On-page
Os elementos principais estão adequados?

### 7. Performance
Existem problemas técnicos relevantes?

### 8. Links
A arquitetura interna funciona?

### 9. Local
Quando aplicável, existe relevância geográfica?

### 10. Conversão
O tráfego orgânico possui caminho claro para a próxima etapa?

## Regra

Uma auditoria deve terminar em prioridades acionáveis,
não apenas em uma lista enorme de problemas.
