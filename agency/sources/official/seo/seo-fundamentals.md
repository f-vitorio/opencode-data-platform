# SEO — Fundamentos

## Objetivo

SEO busca aumentar a descoberta de páginas por meio de mecanismos de busca,
melhorando relevância, acessibilidade, compreensão e experiência.

## Componentes

### SEO técnico
- rastreamento
- indexação
- arquitetura
- performance
- dados estruturados
- URLs
- renderização

### SEO on-page
- intenção de busca
- títulos
- conteúdo
- headings
- links internos
- elementos semânticos

### SEO off-page
- reputação
- referências
- menções
- links obtidos legitimamente

### SEO local
- relevância geográfica
- presença local
- consistência das informações
- experiência do usuário local

## Regra

SEO não deve ser tratado como manipulação de palavras-chave.

O objetivo é construir páginas úteis, acessíveis e relevantes para determinada intenção.
