# Landing Pages — Formulários

## Objetivo

O formulário deve coletar informação suficiente para a finalidade comercial sem criar fricção desnecessária.

## Avaliar

- quantidade de campos
- necessidade de cada campo
- clareza dos rótulos
- mensagens de erro
- feedback após envio
- privacidade
- funcionamento mobile
- integração com CRM quando aplicável

## Regra

Não reduzir campos automaticamente apenas para aumentar conversões.

O objetivo é maximizar o resultado comercial, não somente o número bruto de envios.

## Métrica

Avaliar:

visitas → início do formulário → envio → lead qualificado → oportunidade → venda.
