# Landing Pages — Acessibilidade

## Princípio

Uma landing page deve ser utilizável pelo maior número possível de pessoas.

## Avaliar

- contraste
- hierarquia semântica
- textos alternativos
- foco
- navegação por teclado
- formulários
- mensagens de erro
- tamanho de texto
- interação

## Fonte de referência

WCAG / W3C.

## Regra

Acessibilidade não deve ser tratada apenas como requisito técnico.

Uma interface mais clara e acessível frequentemente também melhora a compreensão e a usabilidade geral.
