# Landing Pages — Relevância para Google Ads

## Objetivo

A landing page deve entregar uma experiência coerente com:

pesquisa → anúncio → promessa → página → ação.

## Princípios

A página deve:

- corresponder à intenção do visitante
- apresentar claramente a oferta
- reduzir ambiguidades
- facilitar a próxima ação
- funcionar adequadamente em dispositivos móveis
- carregar de forma eficiente
- transmitir confiança

## Regra operacional

Não avaliar uma landing page isoladamente.

Avaliar o caminho completo:

1. termo pesquisado
2. anúncio apresentado
3. promessa/mensagem
4. conteúdo da página
5. chamada para ação
6. conversão

## Importante

Uma landing page "bonita" não é necessariamente uma landing page que converte.

O critério principal deve ser adequação ao objetivo comercial.
