# Landing Pages — Mobile

## Princípio

A experiência mobile deve ser tratada como experiência principal quando o tráfego relevante for predominantemente móvel.

## Avaliar

- legibilidade
- tamanho dos elementos
- espaçamento
- navegação
- CTA
- formulários
- imagens
- vídeos
- velocidade
- estabilidade visual

## Regra

Não considerar uma página aprovada apenas porque funciona em desktop.

Testar o fluxo completo no dispositivo ou viewport relevante.
