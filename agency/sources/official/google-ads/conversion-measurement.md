# Google Ads — Mensuração de Conversões

## Fonte
Google Ads Help

## URL
https://support.google.com/google-ads/answer/1722022

## Data de referência
2026-08-16

## Conceito

Conversões representam ações consideradas valiosas para o negócio.

Exemplos:

- compra
- cadastro
- ligação
- outras ações relevantes

## Importância

A mensuração de conversões permite avaliar:

- quais campanhas geram resultados
- quais anúncios geram resultados
- quais palavras-chave geram resultados
- retorno do investimento
- qualidade dos sinais utilizados pelo Smart Bidding

## Primary vs Secondary

A configuração correta de ações de conversão como:

- primárias
- secundárias

é importante porque ações primárias podem ser utilizadas como sinais de otimização.

## Regra operacional

Antes de avaliar performance de uma campanha, verificar:

1. quais conversões estão configuradas
2. quais são primárias
3. quais são secundárias
4. se o rastreamento está funcionando
5. se as conversões representam valor real para o negócio

Nunca assumir que a coluna "Conversões" representa automaticamente leads ou vendas reais.
