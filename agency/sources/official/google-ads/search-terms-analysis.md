# Google Ads — Análise de Termos de Pesquisa

## Objetivo

O relatório de termos de pesquisa ajuda a entender quais pesquisas acionaram os anúncios.

## Uso operacional

Analisar:

- intenção
- relevância
- qualidade
- conversões
- custo
- oportunidades de novas palavras-chave
- oportunidades de palavras-chave negativas

## Processo recomendado

1. Coletar termos
2. Classificar intenção
3. Identificar tráfego irrelevante
4. Identificar oportunidades
5. Avaliar conversões
6. Criar ou ajustar palavras-chave
7. Adicionar negativas quando justificadas
8. Monitorar posteriormente

## Regra

Nunca avaliar uma campanha apenas pelo volume de cliques.

O objetivo é conectar:

pesquisa → anúncio → landing page → conversão → resultado comercial.
