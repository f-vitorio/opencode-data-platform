# Google Ads — Estrutura de Campanhas

## Princípio

A estrutura deve refletir diferenças relevantes de:

- objetivo
- intenção
- oferta
- orçamento
- localização
- estratégia
- mensuração

## Evitar

Não criar campanhas, grupos ou palavras-chave apenas para aumentar artificialmente a quantidade de estruturas.

## Diagnóstico

Antes de alterar uma estrutura existente, verificar:

- objetivo da campanha
- volume
- orçamento
- termos de pesquisa
- conversões
- sobreposição de intenção
- segmentação
- estratégia de lance

## Regra operacional

Estrutura deve facilitar:

- controle
- mensuração
- aprendizado
- otimização
- tomada de decisão

Não existe uma estrutura universal que seja ideal para todas as contas.
