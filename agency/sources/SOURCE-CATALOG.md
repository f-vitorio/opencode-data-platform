# 2. FONTES DE PESQUISA

Utilizadas para complementar conhecimento oficial.

Categorias:

- estudos acadêmicos
- pesquisas de mercado
- estudos de comportamento
- experimentos
- relatórios técnicos
- benchmarks

Regra:

Uma fonte de pesquisa não deve substituir uma fonte oficial
quando a informação for uma regra, política ou especificação
da plataforma.

---

# 3. BENCHMARKS

Benchmarks são utilizados para:

- identificar padrões
- comparar estruturas
- estudar ofertas
- analisar páginas
- estudar posicionamento
- identificar tendências

Benchmark não significa verdade.

Um benchmark deve ser tratado como evidência contextual,
não como regra universal.
