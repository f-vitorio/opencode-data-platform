# REGRAS DE PROVENIÊNCIA

## Objetivo

Garantir que a base da agência diferencie claramente conhecimento
externo, documentação oficial e conhecimento próprio.

## Categorias

### 1. OFICIAL

Existe uma fonte primária identificável.

Exemplos:

- Google
- W3C
- documentação oficial de plataforma
- documentação oficial de produto

### 2. EXTERNA

Fonte não oficial, mas identificável.

Exemplos:

- estudo
- benchmark
- pesquisa
- agência
- especialista
- publicação técnica

### 3. INTERNA

Material produzido pela própria agência.

Exemplos:

- metodologia
- framework
- SOP
- checklist
- template
- processo comercial
- política interna

### 4. A-VALIDAR

Não existe evidência suficiente para determinar a origem.

## Regra

Nunca transformar A-VALIDAR em conhecimento oficial.

Nunca apresentar interpretação interna como regra de uma plataforma.

Nunca inventar uma fonte para justificar uma conclusão.
