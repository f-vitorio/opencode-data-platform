# SISTEMA DE FONTES DA AGÊNCIA

Este diretório contém as fontes utilizadas para construir a base de
conhecimento da agência.

## Diretórios

### inbox/

Fontes recém-coletadas aguardando análise.

### official/

Documentação oficial e fontes primárias.

### research/

Estudos, pesquisas e materiais técnicos.

### benchmarks/

Análises de empresas, agências, páginas, ofertas e mercado.

### archive/

Fontes antigas, rejeitadas ou substituídas.

## Regra principal

A fonte original permanece separada do conhecimento derivado dela.

Fonte ≠ conhecimento.

A fonte fornece evidência.

O conhecimento é a interpretação estruturada e validada dessa evidência.
