# CRO FRAMEWORK

Perguntas:

1. O visitante entende o que está sendo oferecido?
2. Entende para quem é?
3. Entende o próximo passo?
4. Confia na oferta?
5. Existe fricção?
6. A página corresponde à origem do tráfego?
7. A conversão está corretamente medida?

Separar problemas de:

- tráfego;
- mensagem;
- UX;
- oferta;
- tecnologia;
- vendas.
