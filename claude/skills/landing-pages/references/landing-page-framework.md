# LANDING PAGE FRAMEWORK

## Diagnóstico

Antes de criar:

- público;
- oferta;
- intenção;
- origem do tráfego;
- objetivo;
- conversão principal;
- objeções;
- diferenciais;
- provas disponíveis.

## Regra

Não começar pelo design.

Começar por:

Contexto → Oferta → Mensagem → Estrutura → UX → Design → Implementação → Teste.
