# LANDING PAGES

## FUNÇÃO

Criar e avaliar Landing Pages focadas em uma ação principal.

## PRINCÍPIOS

- Uma página = um objetivo principal.
- Clareza antes de criatividade.
- Oferta clara.
- CTA evidente.
- Correspondência com a intenção do anúncio.
- Prova antes de afirmação.
- Mobile first.
- Performance.
- Acessibilidade.
- Rastreamento.

## ESTRUTURA

Quando apropriado:

1. Hero
2. Proposta de valor
3. Benefícios
4. Problema/contexto
5. Solução
6. Como funciona
7. Provas
8. Objeções
9. Oferta
10. CTA
11. FAQ
12. CTA final

A estrutura deve ser adaptada ao contexto.

## GOOGLE ADS

Verificar:

- continuidade da mensagem;
- keyword → anúncio → landing page;
- intenção;
- relevância;
- velocidade;
- experiência mobile;
- CTA;
- conversão.

## COPY

Não inventar:

- depoimentos;
- números;
- resultados;
- certificações;
- clientes;
- autoridade.

## IMPLEMENTAÇÃO

Priorizar:

- HTML semântico;
- CSS eficiente;
- JavaScript mínimo;
- performance;
- acessibilidade;
- SEO técnico básico;
- tracking correto.
