# FRAMEWORK UX/UI/CRO

## Objetivo

Avaliar e melhorar interfaces digitais com foco simultâneo em experiência, clareza, acessibilidade, performance e conversão.

## UX

Avaliar:

- clareza da proposta de valor;
- jornada do usuário;
- hierarquia de informação;
- arquitetura da informação;
- facilidade de navegação;
- redução de fricção;
- clareza dos próximos passos;
- confiança;
- consistência;
- experiência mobile.

Perguntar:

"O usuário entende rapidamente o que é oferecido, para quem é e qual deve ser o próximo passo?"

## UI

Avaliar:

- hierarquia visual;
- tipografia;
- espaçamento;
- contraste;
- consistência;
- alinhamento;
- componentes;
- botões;
- formulários;
- responsividade;
- legibilidade.

Não recomendar alterações estéticas apenas por preferência pessoal.

Toda recomendação visual deve ter uma justificativa funcional.

## CRO

Avaliar:

- oferta;
- proposta de valor;
- CTA;
- intenção do usuário;
- alinhamento anúncio → Landing Page;
- confiança;
- prova social;
- objeções;
- formulário;
- velocidade;
- mobile;
- tracking;
- fricção.

## FRAMEWORK DE DIAGNÓSTICO

Para cada problema identificado:

Problema
→ Evidência
→ Impacto potencial
→ Prioridade
→ Recomendação
→ Hipótese de melhoria
→ Como testar

## PRIORIDADES

Classificar como:

P0 — crítico para conversão ou funcionamento.

P1 — alto impacto potencial.

P2 — melhoria importante.

P3 — melhoria secundária.

## PRINCÍPIO

Não afirmar que uma alteração "vai aumentar conversões" sem evidência.

Preferir:

"pode aumentar"
"é uma hipótese"
"reduz uma possível fricção"
"deve ser testado"

## LANDING PAGE PARA GOOGLE ADS

Verificar especialmente:

1. correspondência com intenção da busca;
2. continuidade entre anúncio e página;
3. proposta de valor acima da dobra;
4. CTA;
5. confiança;
6. objeções;
7. prova;
8. velocidade;
9. mobile;
10. tracking.
