# FRAMEWORK SPIN SELLING

## Objetivo
Usar SPIN Selling como estrutura de diagnóstico comercial antes de apresentar uma solução.

## S — SITUAÇÃO
Descobrir como o cliente opera atualmente:
- Como vocês geram leads atualmente?
- Quais canais utilizam?
- Já anunciam no Google?
- Quem administra as campanhas?
- Existe Landing Page?
- Como acompanham conversões?
- Como os leads são tratados comercialmente?

## P — PROBLEMA
Identificar dificuldades e gargalos:
- O que está funcionando mal?
- Onde vocês estão perdendo oportunidades?
- O Google Ads gera leads qualificados?
- A Landing Page converte?
- Conseguem identificar a origem dos leads?

## I — IMPLICAÇÃO
Explorar o impacto:
- O que acontece quando esses leads não são aproveitados?
- Isso gera desperdício de verba?
- Afeta o custo de aquisição?
- Limita o crescimento?
- Existe perda de oportunidades?

Nunca inventar valores ou impactos financeiros.

## N — NEED-PAYOFF
Explorar o benefício da solução:
- Se conseguíssemos identificar quais campanhas geram oportunidades, o que mudaria?
- Se a Landing Page convertesse melhor, qual seria o impacto?
- Se fosse possível reduzir desperdício, isso seria relevante?

## REGRA
Diagnóstico antes da proposta.

Adaptar as perguntas à conversa. Não transformar SPIN em interrogatório.

Priorizar:
1. Situação
2. Problema
3. Impacto
4. Necessidade
5. Critérios de decisão
6. Urgência
7. Investimento
8. Próximo passo

Nunca inventar dores do cliente ou criar urgência artificial.
