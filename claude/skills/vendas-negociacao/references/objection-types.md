# TIPOS DE OBJEÇÕES COMERCIAIS

## Objetivo

Identificar a causa real de uma objeção antes de responder.

Nunca assumir que uma objeção de preço significa simplesmente falta de dinheiro.

## 1. PREÇO

Exemplos:

- Está caro.
- Seu preço está acima do concorrente.
- Não consigo investir isso agora.

Investigar:

- Comparação com quê?
- Existe orçamento definido?
- O cliente entende o escopo?
- O valor percebido é suficiente?
- O problema é preço ou prioridade?

Resposta estratégica:

1. reconhecer;
2. investigar;
3. esclarecer valor;
4. ajustar escopo se necessário;
5. negociar somente com contrapartida quando apropriado.

Nunca oferecer desconto automaticamente.

## 2. VALOR NÃO PERCEBIDO

Sinais:

- Não entendi por que custa isso.
- Parece simples.
- Meu sobrinho consegue fazer.
- É só uma página/anúncio/site.

Estratégia:

Explicar complexidade, responsabilidade, estratégia, processo e resultado esperado sem prometer resultados garantidos.

## 3. CONFIANÇA

Sinais:

- Preciso conhecer melhor seu trabalho.
- Você já fez isso para empresas como a minha?
- Tenho receio de contratar.

Estratégia:

Apresentar processo, evidências reais disponíveis, escopo, responsabilidades e próximos passos.

Nunca inventar cases, números ou experiência.

## 4. MOMENTO / PRIORIDADE

Sinais:

- Agora não.
- Talvez no próximo mês.
- Não é prioridade.

Investigar:

- O problema continuará existindo?
- Existe uma data ou evento relevante?
- O projeto foi adiado ou abandonado?

Não criar urgência artificial.

## 5. AUTORIDADE / DECISÃO

Sinais:

- Preciso falar com meu sócio.
- Preciso consultar meu marido/esposa.
- Quem decide é meu diretor.

Descobrir:

- Quem participa da decisão?
- Quais critérios serão avaliados?
- O que essa pessoa precisa saber?

Ajudar o cliente a levar uma proposta clara para o decisor.

## 6. COMPARAÇÃO

Sinais:

- Outra agência cobra menos.
- Recebi uma proposta mais barata.

Não atacar concorrentes.

Comparar:

- escopo;
- estratégia;
- nível de acompanhamento;
- responsabilidade;
- prazo;
- entregáveis;
- experiência;
- modelo de atendimento.

## 7. PRAZO

Sinais:

- Preciso para amanhã.
- Quero começar imediatamente.

Avaliar capacidade operacional e impacto no escopo.

Urgência pode justificar preço diferente quando houver maior complexidade ou prioridade operacional.

## 8. ESCOPO

Sinais:

- Pode incluir mais uma página?
- Pode fazer também o SEO?
- Pode colocar mais alguns vídeos?

Não aceitar expansão informal de escopo.

Responder apresentando:

- o que está incluído;
- o que é adicional;
- impacto em prazo;
- impacto em investimento.

## REGRA GERAL

Objeção → investigação → causa raiz → resposta → próximo passo.

Nunca:

Objeção → desconto automático.

## QUANDO RECUSAR

Considerar não avançar quando houver:

- expectativas irreais;
- exigência de resultados garantidos;
- desrespeito recorrente;
- tentativa constante de expansão sem pagamento;
- condições incompatíveis com a operação;
- risco comercial excessivo.
