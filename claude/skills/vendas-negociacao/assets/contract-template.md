# REGRA PARA A SKILL

Todo contrato gerado deve ser identificado como:

"MINUTA DE CONTRATO — AGUARDANDO REVISÃO/APROVAÇÃO"

A skill deve:

1. comparar com a proposta aprovada;
2. verificar escopo;
3. verificar preço;
4. verificar prazo;
5. verificar forma de pagamento;
6. identificar informações faltantes;
7. sinalizar cláusulas que exigem revisão jurídica.

Nunca enviar automaticamente ao cliente.
