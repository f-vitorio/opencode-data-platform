# SEQUÊNCIA DE FOLLOW-UP

## Objetivo

Fazer acompanhamento profissional sem pressionar artificialmente o cliente.

## FOLLOW-UP 1

Após a proposta:

Objetivo:
Confirmar recebimento e abrir espaço para dúvidas.

Estrutura:

- confirmar envio;
- perguntar se conseguiu analisar;
- oferecer esclarecimento;
- não pressionar.

## FOLLOW-UP 2

Após alguns dias:

Objetivo:
Descobrir se existe alguma dúvida ou impedimento.

Perguntar:

- ficou alguma dúvida sobre a proposta?
- existe algum ponto que precisa ser ajustado?
- o escopo está adequado?
- existe algum fator impedindo a decisão?

## FOLLOW-UP 3

Se houver silêncio:

Ser objetivo.

Exemplo de estrutura:

"Queria apenas confirmar se o projeto continua sendo uma prioridade para vocês ou se preferem deixar para outro momento."

## FOLLOW-UP COM OBJEÇÃO

Se o cliente informou uma objeção anteriormente, retomar especificamente o ponto.

Exemplo:

"Na nossa última conversa você comentou sobre o investimento. Queria entender se esse continua sendo o principal ponto ou se surgiu alguma outra questão."

## FOLLOW-UP DE DECISÃO

Quando todas as informações estiverem disponíveis:

Perguntar pelo próximo passo.

Exemplos:

- podemos avançar?
- gostaria que eu ajustasse a proposta?
- faz sentido iniciarmos?
- existe alguma informação que falta para tomar a decisão?

## REGRA

Não enviar mensagens repetitivas.

Cada follow-up deve ter um motivo.

## EVITAR

- "E aí?"
- "Alguma novidade?"
- "Vai fechar?"
- pressão artificial;
- falsa escassez;
- ameaças;
- descontos automáticos.

## PRINCÍPIO

Follow-up deve gerar clareza, não pressão.
