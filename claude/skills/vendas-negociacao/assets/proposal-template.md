> TEMPLATE INTERNO — NÃO ENVIAR ESTE ARQUIVO DIRETAMENTE AO CLIENTE.

Este documento é um modelo para geração de propostas comerciais personalizadas.

A proposta final deve ser adaptada ao contexto específico do cliente.

---

# REGRAS PARA GERAÇÃO DA PROPOSTA

Antes de gerar uma proposta:

1. Identificar o problema principal do cliente.
2. Identificar o objetivo desejado.
3. Identificar o serviço ou solução mais adequada.
4. Consultar `service-catalog.md` para validar escopo.
5. Consultar `pricing.md` para validar preço.
6. Verificar se existem informações insuficientes.
7. Não inventar informações.
8. Não prometer resultados garantidos.
9. Não apresentar desconto automaticamente.
10. Priorizar valor antes de preço.
11. Diferenciar honorários da agência de investimentos de terceiros.
12. Definir claramente o que está e o que não está incluído.
13. Identificar próximos passos.

A proposta deve ser marcada como:

**PROPOSTA COMERCIAL — RASCUNHO**

até que o usuário aprove explicitamente.

# REGRAS DE NEGOCIAÇÃO APLICADAS À PROPOSTA

## Preço recomendado

Utilizar o preço recomendado como ponto de partida.

## Preço mínimo

Nunca apresentar automaticamente.

O preço mínimo é uma referência interna para negociação.

## Desconto

Nunca oferecer desconto simplesmente porque o cliente pediu.

Antes de conceder:

1. identificar a causa da objeção;
2. verificar se é realmente preço;
3. avaliar escopo;
4. avaliar prazo;
5. avaliar duração do contrato;
6. avaliar pagamento antecipado;
7. avaliar contratação de pacote.

Sempre que possível:

**Concessão → Contrapartida**

Exemplo:

"Podemos avaliar uma condição diferente caso o contrato tenha prazo maior."

Nunca prometer uma condição sem autorização do usuário.

---

# REGRAS PARA PROPOSTAS DE SERVIÇOS RECORRENTES

Quando o serviço for mensal:

- destacar mensalidade;
- explicar o que está incluído;
- separar investimento de mídia quando aplicável;
- esclarecer o início da gestão;
- esclarecer prazo contratual quando definido;
- evitar apresentar o serviço como garantia de resultado.

---

# REGRAS PARA PROPOSTAS DE PROJETO

Quando o serviço for projeto:

- definir escopo;
- definir entregáveis;
- definir prazo;
- definir número de revisões quando aplicável;
- definir condições de pagamento;
- definir o que não está incluído;
- definir critérios de aceite quando necessário.

---

# REGRAS PARA PACOTES

Quando houver mais de um serviço:

1. apresentar o problema central;
2. explicar a função de cada componente;
3. evitar transformar a proposta em uma lista de tarefas;
4. apresentar a solução integrada;
5. demonstrar o valor do conjunto;
6. definir o preço individual de referência quando útil;
7. apresentar o investimento do pacote;
8. qualquer desconto deve ser autorizado.

---

# REGRA DE APROVAÇÃO

Toda proposta gerada pela skill deve inicialmente ser marcada:

> **PROPOSTA COMERCIAL — RASCUNHO**

A proposta só pode ser considerada aprovada após comando explícito do usuário.

Exemplo:

**APROVAR PROPOSTA**

Antes da aprovação:

- não enviar;
- não compartilhar;
- não considerar contrato fechado;
- não gerar comunicação como se o cliente já tivesse aceitado.
