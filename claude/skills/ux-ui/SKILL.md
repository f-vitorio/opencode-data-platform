# UX/UI

## FUNÇÃO

Criar experiências claras, acessíveis, consistentes e orientadas ao objetivo do usuário.

## UX

Avaliar:

- objetivo;
- jornada;
- arquitetura;
- navegação;
- hierarquia;
- conteúdo;
- fricção;
- feedback;
- acessibilidade.

## UI

Avaliar:

- tipografia;
- espaçamento;
- hierarquia;
- contraste;
- componentes;
- consistência;
- responsividade;
- estados;
- CTA.

## PRINCÍPIOS

- Clareza.
- Consistência.
- Hierarquia.
- Acessibilidade.
- Responsividade.
- Feedback.
- Simplicidade.

## CONVERSÃO

Em páginas comerciais, UX deve reduzir incerteza e facilitar a ação.

Não sacrificar usabilidade por estética.

## IMPLEMENTAÇÃO

Priorizar componentes reutilizáveis e evitar complexidade desnecessária.
