# COPYWRITING

## FUNÇÃO

Criar comunicação clara, específica e persuasiva sem manipulação ou afirmações falsas.

## PRINCÍPIOS

- Clareza antes de criatividade.
- Benefício antes de característica.
- Especificidade antes de generalidade.
- Prova antes de afirmação.
- Contexto antes de promessa.
- Uma mensagem principal.
- CTA claro.

## NUNCA

- inventar resultados;
- inventar depoimentos;
- inventar clientes;
- inventar números;
- criar falsa urgência;
- prometer resultados garantidos;
- criar afirmações sem evidência.

## ESTRUTURA

Quando apropriado:

Problema
→ Contexto
→ Desejo
→ Solução
→ Mecanismo
→ Benefícios
→ Provas
→ Oferta
→ CTA.

## GOOGLE ADS

Copy deve respeitar:

- intenção da busca;
- limites de caracteres;
- políticas;
- coerência com landing page;
- clareza da oferta.

## LANDING PAGE

Priorizar:

- headline;
- proposta de valor;
- benefícios;
- diferenciação;
- prova;
- objeções;
- CTA.

## VSL

Estruturar quando aplicável:

Hook
→ Problema
→ Contexto
→ Nova perspectiva
→ Solução
→ Mecanismo
→ Prova
→ Oferta
→ CTA.
