# HEADLINES

Uma boa headline deve comunicar rapidamente:

- o que é;
- para quem;
- benefício ou proposta de valor.

Testar diferentes ângulos:

- benefício;
- problema;
- especificidade;
- resultado desejado sem garantia;
- mecanismo;
- diferenciação.

Evitar clickbait e promessas não comprovadas.
