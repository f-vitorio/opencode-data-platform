# SOURCE HIERARCHY

## Prioridade das fontes

1. Instrução atual do usuário
2. Referências internas das skills e arquivos do projeto
3. Documentação oficial / fonte primária
4. Fontes externas confiáveis
5. Conhecimento geral do modelo

## Regras

- Nunca substituir uma regra comercial interna por informação externa sem solicitação do usuário.
- Preços, escopos, processos e regras internas são definidos pelas referências internas quando existentes.
- Para informações atuais de plataformas, priorizar documentação oficial.
- Se houver conflito entre fontes, informar o conflito e seguir a fonte de maior prioridade.
- Nunca inventar preços, entregáveis, resultados, cases, depoimentos ou políticas.
