# WEB RESEARCH POLICY

Pesquisar externamente somente quando isso melhorar materialmente a precisão ou atualidade da resposta.

## Pesquisar quando

- O usuário pedir informação atual ou recente.
- Políticas de plataformas puderem ter mudado.
- Recursos, limites ou requisitos de plataformas puderem ter mudado.
- O usuário pedir dados atuais de mercado, concorrentes ou preços externos.

## Prioridade

1. Fonte oficial
2. Documentação técnica primária
3. Fonte especializada confiável
4. Comunidade, quando útil para experiências práticas

## Não usar pesquisa externa para substituir

- Preços internos
- Escopo interno
- Regras comerciais internas
- Posicionamento da agência
- Processos internos

Se a informação não puder ser confirmada, declarar a limitação.
